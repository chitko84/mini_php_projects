# PHP API Integration Project

This mini project demonstrates:
- HTML form input
- cURL GET requests
- JSON decoding
- Error handling
- Displaying external API data

It uses the public Open-Meteo geocoding and weather APIs and does not require an API key.

## Requirements
- PHP with the cURL extension enabled
- Internet connection

## Run
1. Put the folder inside your PHP server directory.
2. Open `index.php`.
3. Enter a city such as `Kuala Lumpur`.
4. The app finds the city's coordinates and displays current weather data.
