# PHP Phase 11 Mini Projects

This package contains three separate projects:

1. `01_Login_System`
   - Registration
   - Secure login
   - Sessions
   - Logout
   - MySQL

2. `02_Student_CRUD_App`
   - Create
   - Read
   - Update
   - Delete
   - MySQL

3. `03_API_Integration`
   - City input form
   - cURL
   - JSON
   - Open-Meteo API
   - Error handling

Recommended learning order:
1. CRUD App
2. Login System
3. API Integration
