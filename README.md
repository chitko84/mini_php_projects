# PHP Phase 11 Mini Projects

This repository contains three beginner-friendly PHP projects created to practice core backend development concepts such as MySQL, CRUD operations, sessions, authentication, APIs, cURL, and JSON.

## Projects

| Project | Main Features |
|---|---|
| `01_Login_System` | Registration, Login, Sessions, Logout, MySQL |
| `02_Student_CRUD_App` | Create, Read, Update, Delete, MySQL |
| `03_API_Integration` | City Input, cURL, JSON, Open-Meteo API, Error Handling |

## 1. Login System

A simple authentication system built with PHP and MySQL.

### Features
- User registration
- Secure login
- Password hashing
- Sessions
- Logout
- MySQL database connection

## 2. Student CRUD App

A basic student management system that demonstrates CRUD operations.

### Features
- Create student records
- View student records
- Update student information
- Delete student records
- MySQL integration

## 3. API Integration

A simple weather application using the Open-Meteo API.

### Features
- City input form
- PHP cURL requests
- JSON response handling
- Weather API integration
- Error handling

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- cURL
- JSON
- Open-Meteo API

## Recommended Learning Order

1. `02_Student_CRUD_App`
2. `01_Login_System`
3. `03_API_Integration`

2. Place the project folder inside the `htdocs` directory.
