# Student CRUD App

CRUD means:
- Create = INSERT
- Read = SELECT
- Update = UPDATE
- Delete = DELETE

## Setup
1. Create/import the database using `database.sql`.
2. Update `db.php` if your MySQL credentials differ.
3. Put the folder inside your PHP server directory.
4. Open `index.php`.

The app supports:
- Add student
- View students
- Edit student
- Delete student
- Prepared statements for writes
